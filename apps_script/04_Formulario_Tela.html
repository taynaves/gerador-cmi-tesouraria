A Referência é gerada pelo sistema e não se digita — é ela que amarra cada comprovante ao Histórico. Só há dois motivos para mudá-la, e os dois ficam registrados com o motivo que você escrever aqui.
 

2. De onde sai e para onde vai

Destino — para onde o valor vai

 

3. Que movimentação é esta

Escolha as duas contas.
Mesma PIA é movimentação interna; PIAs diferentes é transferência, entre departamentos ou entre administrações.
Como o dinheiro anda.
Saque sozinho é ambíguo.
Que espécie de movimentação é.
Só as que valem para estas contas.
 
 

4. Valor

Pode escrever 1800, 1.800,00 ou 1800,50.
 
Um comprovante em lote só pode reunir lançamentos da mesma etapa, do mesmo mês, da mesma origem e destino (ou da mesma conta ACG, no caso de cartões) e do mesmo tipo.
Total: R$ 0,00
 

5. Quem assina

São necessárias no mínimo 3 assinaturas para anexar no SIGA, mas o PDF pode ser gerado com menos — os espaços saem em branco, para caneta ou carimbo. Nome e cargo saem no documento como estão no cadastro, sem caixa alta.
